# Calculator – CodeAlpha Internship Project

A simple, responsive, and interactive Calculator built using **HTML, CSS, and JavaScript** as part of my CodeAlpha Internship.

## About the Project

This Calculator performs basic arithmetic operations through a clean and user-friendly interface. It includes interactive buttons, keyboard support, and error handling for invalid calculations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Clear All (AC)
- Delete Last Character (DEL)
- Decimal Number Support
- Keyboard Input Support
- Error Handling
- Responsive User Interface

## Technologies Used

- HTML5 – Structure
- CSS3 – Styling and Layout
- JavaScript – Functionality and Logic

## How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/Amirkhan786-coder/CodeAlpha_Calculator.git
```

2. Open the project folder:

```bash
cd CodeAlpha_Calculator
```

3. Open `index.html` in your web browser.

4. Start using the Calculator!

## Keyboard Shortcuts

| Key | Function |
|---|---|
| 0–9 | Enter numbers |
| +, -, *, / | Arithmetic operators |
| Enter | Calculate result |
| Backspace | Delete last character |
| Escape | Clear display |
| % | Percentage |
| . | Decimal point |
